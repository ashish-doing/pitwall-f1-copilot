System Architecture

How PitWall Works

Three AI systems working in concert — real telemetry data, regulation-aware language reasoning, and reinforcement learning trained on actual race outcomes.

01 — DATA
📡
FastF1 Telemetry
Official F1 timing API. Lap times, tyre compounds, pit stop laps from 2022–2024 seasons.
02 — RULES
📋
Docling + FIA Regs
IBM Docling parses FIA Sporting Regulations PDF, extracting compound rules and pit window constraints.
03 — REASON
🧠
IBM Granite 4.1 8B
Granite receives telemetry + regulation context, generates explainable strategy analysis.
04 — LEARN
🤖
Q-Learning Agent
RL agent trained on 23,400 real decisions. Outputs Stay Out / Pit Now / Pit in 2 with Q-values.

Race Strategy Analysis

Select any season (2022–2024), Grand Prix, and driver. FastF1 loads real telemetry. IBM Granite — with Docling regulation context — analyzes the complete race strategy.

  • Real FastF1 telemetry — not simulated data
  • FIA regulation context injected via Docling
  • 3-paragraph strategic breakdown from Granite
  • Identifies optimal vs suboptimal decisions
  • Suggests alternative strategies
Sample Granite Output — Monaco 2024, LEC
Driver: LEC | Race: Monaco GP 2024 Laps: 78 | Best: 75.162s Compounds: MEDIUM → HARD ━━ Strategy Assessment ━━ Safety Car pit on lap 1 was textbook — free stop, zero track position loss. ━━ Regulation Check ━━ Two-compound rule: satisfied ✓ Pit window timing: optimal ✓

Live Pit Window Advisor

Adjust sliders for current lap, tyre age, and lap time delta. IBM Granite gives a direct pit/stay-out recommendation simulating real pit wall decision support.

  • Real-time Granite recommendation
  • Tyre compound context aware
  • Lap delta degradation analysis
  • 2–3 sentence direct reasoning
  • Simulates actual pit wall workflow
Sample Output — Lap 25, MEDIUM, +0.5s
Input State: Lap: 25 | Compound: MEDIUM Tyre Age: 20 laps | Δ: +0.5s Granite Recommendation: STAY OUT — delta of +0.5s is within acceptable window. With 20 laps remaining, pitting now risks undercut exposure.

RL Pit Optimizer

The Q-learning agent — trained on 23,400 real F1 lap decisions — outputs a pit recommendation with full Q-value transparency. Not a black box.

  • Trained on 5 real F1 races (2023–2024)
  • 23,400 lap state → decision pairs
  • Full Q-value breakdown shown
  • Confidence score from Q-value margin
  • Explainable — see exactly why it decides
Sample RL Output — MEDIUM, 25 laps old
State: Compound: MEDIUM | Age: 25 Laps Remaining: 30 | Δ: +0.8s Q-Values: Stay Out → 7.600 Pit Now → 14.978 ◀ MAX Pit in 2 → 7.506 Decision: PIT NOW | Conf: 65.2%
IBM Technologies

Built with IBM AI

PitWall uses two core IBM technologies as required by the challenge — Granite for reasoning and Docling for document intelligence.

IBM TECHNOLOGY

Granite 4.1 8B

IBM's flagship open-source language model. Core reasoning engine for strategy analysis and pit window recommendations. Receives telemetry + regulation context, outputs explainable strategic analysis.

IBM TECHNOLOGY

Docling

IBM's document intelligence library. Parses the FIA Sporting Regulations PDF, extracts tyre compound rules and pit stop regulations, injects this context into every Granite prompt.

OPEN SOURCE

FastF1 + RL Agent

Official F1 telemetry API for real race data (2022–2024). Combined with a custom Q-Learning agent trained on 23,400 real lap decisions from 5 F1 races.
